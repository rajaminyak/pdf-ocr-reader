# Phase 2: OCR — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make image-only pages searchable. Add a RapidOCR wrapper that returns text lines with bounding boxes, wire it into `Document` as the fallback when a page has no usable native text layer, and persist per-page OCR results to the on-disk cache keyed by file hash so a re-opened document is instant.

**Architecture:** New `ocr` module (RapidOCR, process-global engine, CPU) → `list[Span]`, one span per detected text line, bbox = the axis-aligned bounding rectangle of RapidOCR's 4-point polygon in the pixel space of the image that was OCR'd (a page rendered at `ocr.OCR_DPI`). `Document` gains: a per-page OCR store loaded from `cache` on open, `page_spans` falling through to OCR-and-persist for non-native pages, and `ocr_all(progress)` to sweep the whole document (used by the CLI now, by the GUI's background thread in Phase 3). `search` and `cli` need only small changes — they already go through `Document.page_spans`.

**Tech Stack:** adds `rapidocr` + `onnxruntime` (pure pip, CPU, bundles its own ONNX models — no external binaries). Everything else unchanged from Phase 1.

**Spec:** `docs/superpowers/specs/2026-09-10-pdf-ocr-reader-design.md`

## Global Constraints

- The core still never imports PySide6 (Phase 1's `test_core_has_no_gui_dep` must keep passing; add `pdf_ocr_reader.ocr` to it).
- RapidOCR's engine is a process-global singleton and is **not thread-safe** — the module exposes one lazily-created engine; callers must not OCR from two threads at once (Phase 3's GUI uses a single worker thread).
- OCR spans are **line-level** (RapidOCR returns lines, not words); native spans stay word-level. `search` treats both the same (substring match on `Span.text`); this is intentional — a line-level highlight reads fine.
- `Span.bbox` coordinate space differs by source: native spans are in PDF points; OCR spans are in pixels of a render at `ocr.OCR_DPI`. `Document` exposes `ocr_dpi` so a consumer (Phase 3) can convert. Do not mix the two spaces.
- The cache stores **only** OCR'd pages (native-text pages are re-derived from the PDF instantly). Cache write failures never raise (Phase 1's `cache.write` already swallows `OSError`).
- A page whose OCR fails (engine error, unrenderable page) yields `[]` spans and is recorded in the cache as `[]` with an `"error"` note, so it is not retried every open; the rest of the document keeps working.

```python
from __future__ import annotations

from pdf_ocr_reader.models import Span

OCR_DPI = 300

_engine = None


class OcrError(Exception):
    pass


def _get_engine():
    global _engine
    if _engine is None:
        from rapidocr import RapidOCR

        _engine = RapidOCR()
    return _engine


def ocr_image(png_bytes: bytes) -> list[Span]:
    engine = _get_engine()
    try:
        result = engine(png_bytes)
    except Exception as exc:  # noqa: BLE001 - engine failure, surface as OcrError
        raise OcrError(str(exc)) from exc

    if result is None or not result.txts:
        return []

    spans: list[Span] = []
    for text, box in zip(result.txts, result.boxes):
        if not text or not text.strip():
            continue
        xs = [float(p[0]) for p in box]
        ys = [float(p[1]) for p in box]
        spans.append(Span(text=text, bbox=(min(xs), min(ys), max(xs), max(ys))))
    return spans
```

### Task 3: `Document` — OCR fallback + cache

**Files:**
- Modify: `src/pdf_ocr_reader/document.py`
- Test: `tests/test_document_ocr.py`

**Interfaces:**
- `Document` gains `ocr_dpi: int` (= `ocr.OCR_DPI`).
- `page_spans(page_index)` — unchanged signature; new behaviour: native readable → native spans; else OCR spans, in this precedence: already in the in-memory store → return; else render the page at `ocr_dpi`, `ocr.ocr_image` it, store in memory, persist the whole store to `cache`, return. An `OcrError` on a page → store `[]` for it (with an error note in the cache) and return `[]`.
- `ocr_all(progress: Callable[[int, int], None] | None = None) -> None` — for every page that would need OCR (i.e. not native-readable and not already cached), OCR it; call `progress(done, total)` after each, where `total` is the count of pages needing OCR at the start.
- On `Document.open`, if `cache.read(content_hash)` returns a payload whose `ocr_dpi` matches `ocr.OCR_DPI`, load its `pages` into the in-memory store (parsing `Span.from_dict`). A stale-dpi payload is ignored (re-OCR).

Extend `__init__`:
```python
    def __init__(self, path: str, doc: fitz.Document) -> None:
        self.path = path
        self._doc = doc
        self.page_count = doc.page_count
        self.content_hash = _hash_file(path)
        self.ocr_dpi = ocr.OCR_DPI
        self._ocr_pages: dict[int, list[Span]] = {}
        self._ocr_errors: set[int] = set()
        self._load_cache()

    def _load_cache(self) -> None:
        payload = cache.read(self.content_hash)
        if not payload or payload.get("ocr_dpi") != self.ocr_dpi:
            return
        for key, raw_spans in payload.get("pages", {}).items():
            spans = [Span.from_dict(d) for d in raw_spans]
            self._ocr_pages[int(key)] = spans
            if not spans and key in payload.get("errors", []):
                self._ocr_errors.add(int(key))

    def _persist_cache(self) -> None:
        cache.write(
            self.content_hash,
            {
                "path": self.path,
                "page_count": self.page_count,
                "ocr_dpi": self.ocr_dpi,
                "engine": "rapidocr",
                "created_at": datetime.now(timezone.utc).isoformat(),
                "pages": {str(i): [s.as_dict() for s in v] for i, v in self._ocr_pages.items()},
                "errors": [str(i) for i in sorted(self._ocr_errors)],
            },
        )
```

Replace `page_spans`:
```python
    def page_spans(self, page_index: int) -> list[Span]:
        native = textlayer.native_page_spans(self._doc[page_index])
        if native is not None:
            return native
        if page_index in self._ocr_pages:
            return self._ocr_pages[page_index]
        spans = self._ocr_page(page_index)
        self._ocr_pages[page_index] = spans
        self._persist_cache()
        return spans

    def _ocr_page(self, page_index: int) -> list[Span]:
        try:
            rendered = renderer.render_page(self._doc[page_index], dpi=self.ocr_dpi)
            return ocr.ocr_image(rendered.png_bytes)
        except ocr.OcrError:
            self._ocr_errors.add(page_index)
            return []
```

Add `ocr_all` and a helper to know which pages need OCR:
```python
    def _pages_needing_ocr(self) -> list[int]:
        pending = []
        for i in range(self.page_count):
            if i in self._ocr_pages:
                continue
            if textlayer.native_page_spans(self._doc[i]) is not None:
                continue
            pending.append(i)
        return pending

    def ocr_all(self, progress=None) -> None:
        pending = self._pages_needing_ocr()
        total = len(pending)
        for done, page_index in enumerate(pending, start=1):
            self._ocr_pages[page_index] = self._ocr_page(page_index)
            self._persist_cache()
            if progress is not None:
                progress(done, total)
```
