PDF OCR Reader - Panduan Awal
=============================

Fungsi
------
Buka PDF apa pun - termasuk halaman hasil scan yang tidak ada teksnya -
dan cari isinya. Halaman hasil scan akan di-OCR (dikenali teksnya) secara
otomatis, jadi bisa mencari kata, tag, atau klausa tanpa membaca halaman
satu per satu.

Cara pakai
----------
1. Buka "PDF OCR Reader" dari Start Menu (atau shortcut desktop).
2. Klik "Open..." (atau menu File > Open) lalu pilih file PDF. Bisa juga
   men-drag file PDF ke jendela aplikasi.
3. Halaman 1 langsung muncul. Halaman hasil scan di-OCR di latar
   belakang - progress bar di bawah menunjukkan "OCR 3 / 14". Biarkan
   jendela tetap terbuka; laporan scan yang tebal bisa perlu beberapa
   menit. Aman untuk scroll dan membaca selama proses OCR berjalan.
4. Ketik di kotak pencarian (kanan atas). Hasil muncul di panel kanan -
   klik salah satu untuk lompat ke halaman itu dengan bagian yang cocok
   ditandai kuning.
5. Menu File > "Save searchable copy..." membuat PDF baru dengan lapisan
   teks tak terlihat, sehingga bisa di-Ctrl+F di Acrobat, Edge, atau
   pembaca PDF mana pun. File asli TIDAK PERNAH diubah.

Catatan
-------
- Dokumen yang pernah dibuka akan terbuka seketika - hasil OCR-nya
  tersimpan di %LOCALAPPDATA%\PdfOcrReader. Menu Tools > "Clear OCR cache"
  untuk mengosongkannya.
- OCR dan semua proses berjalan di komputer ini. Tidak ada file yang
  keluar dari PC, tidak butuh internet.
- Pengaturan dan cache OCR tetap ada meski aplikasi di-uninstall / install
  ulang.
- Tampilan aplikasi berbahasa Inggris; panduan ini hanya terjemahan cara
  pakainya.
