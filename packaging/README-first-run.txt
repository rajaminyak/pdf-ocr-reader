PDF OCR Reader - First run
===========================

What it does
------------
Open any PDF - including scanned pages with no text - and search inside it.
Scanned pages are OCR'd (text recognition) automatically so you can find a
word, tag, or clause without reading page by page.

Using it
--------
1. Launch "PDF OCR Reader" from the Start Menu (or the desktop shortcut).
2. Click "Open..." (or File > Open) and pick a PDF. Or drop a PDF file
   onto the window.
3. Page 1 appears at once. Scanned pages are OCR'd in the background -
   the progress bar at the bottom shows "OCR 3 / 14". Keep the window
   open; a big scanned report can take a few minutes. It is safe to
   scroll and read while OCR runs.
4. Type in the search box (top right). Results appear on the right -
   click one to jump to that page with the match highlighted in yellow.
5. File > "Save searchable copy..." writes a new PDF with an invisible
   text layer, so you can Ctrl+F it in Acrobat, Edge, or any reader.
   The original file is never changed.

Notes
-----
- A document you have opened before opens instantly - its OCR result is
  cached under %LOCALAPPDATA%\PdfOcrReader. Tools > "Clear OCR cache"
  empties it.
- OCR and everything else runs on this computer. No file leaves the PC,
  no internet needed.
- Your settings and the OCR cache survive an uninstall / reinstall.
- The interface is in English; the Indonesian guide (README-first-run.id.txt)
  only translates these instructions.
